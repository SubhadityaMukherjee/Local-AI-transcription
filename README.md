# Local-AI-transcription

I wanted to build a customizable frontend for Whisper.cpp. I know there are a lot of them, but this works for my own quirks

- Note that a bunch of this was vibe coded using Claude. Please do not try to use this in production. This was mainly meant as a utlity script first.

## Setup

- Make sure you have installed `uv` and `ollama` and `git`
- Clone this repo
- I have ONLY tested this out on a Mac with an M chip. I was not trying to make it a universal tool
- Once you have all this, run `./setup.sh` in this directory
- If all is well, run `./run.sh` and you should be good to go
